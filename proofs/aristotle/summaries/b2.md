**What is proved**
- **`Kxx.contract`:** for every in-range argument satisfying the function's `kani::requires`, if the call returns, the result satisfies its `kani::ensures`. Parameter names in the `ensures` mean the values the caller passed.
- **No-panic part of `Kxx.nopanic`:** under the same conditions, no execution of the body panics. Overflow checks are on, and every overflow-checked `-` in these bodies is guarded.
- **Unreachable errors:**
  - In K15, once the guard passes, the `checked_add` cannot overflow, so `CounterOverflow` never happens.
  - In K31, once both inputs are below `SOCIAL_LOSS_DEN`, the `checked_add` cannot overflow, so the `?` never returns early.
- **Build:** these are about the deployed bodies: default features, no `cfg(kani)`, release profile with overflow checks.
- **Object size:** the results assume every Rust object is smaller than \(2^{56}\) bytes.
