## Open questions
- **How should the A2/A6 constant clauses be verified?** Associated constants have no code of their own, because rustc inlines their values where they are used. In the deployed build `wide_math` is a private module, so a separate crate cannot reach these constants through the public API. `U256::ONE` is not used by any deployed `wide_math` function. The compiled values of the other constants are pinned only through the proved functions that use them. The options are:
  - (a) accept that indirect coverage plus the source definitions;
  - (b) allow a harness that compiles `src/wide_math.rs` unchanged and returns each constant from a function, so the values can be proved formally.
