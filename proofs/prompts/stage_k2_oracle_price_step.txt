The target is the function that bounds what an oracle can do to a market's effective price: `canonical_accrual_price_step_v16` in src/v16.rs (a free `pub fn`). Each accrual step calls it once per slot with the current effective price, the oracle's target price, a fixed anchor price, the configured cap in basis points per slot, whether the asset has open interest, and a remainder carried from the previous step. It now carries a `kani::ensures` contract (the `cfg_attr` right above it). Kani checks that contract only for 8-bit inputs: the division by MAX_MARGIN_BPS (10,000) puts wider checks beyond it. Please prove, for every input (all six parameters over their whole types), about the deployed function body (no cfg(kani), default features, this crate's release profile with overflow-checks = true):

- KP.contract: the function satisfies its ensures clause.
- KP.nopanic: no execution of the function panics.
- KP.envelope: the bound summed over steps. Fix `target`, `cap_anchor` and `max_change_bps`, and `exposed = true`. Let a sequence of calls start from price `p_0` and remainder `r_0`, each call taking the price and remainder the previous one returned, all returning Ok, for `n` calls. Then `|p_n - p_0| * MAX_MARGIN_BPS <= n * cap_anchor * max_change_bps + r_0` (exact integers), and every `p_i` lies between `p_0` and `target` inclusive. (The effective price can never move faster than the configured cap, whatever target price the oracle reports, and never past the target.)
- KP.reaches: under the same assumptions, if `n * cap_anchor * max_change_bps + r_0 >= |target - p_0| * MAX_MARGIN_BPS` then `p_n == target`. (The price does get to the target once the allowance covers the distance.)

State KP.envelope and KP.reaches about the function itself (for instance by induction on n with the function applied repeatedly), not about a model of it. If the ensures clause is wrong for some input, a counterexample (the six values) is the most useful result. Record each finished property before starting the next. In the summary, list for each property its status and anything it assumes about library functions.
