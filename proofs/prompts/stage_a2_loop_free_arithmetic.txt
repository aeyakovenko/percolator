In this task prove the properties whose functions contain no loop, in this order. Record each finished property before starting the next, so finished results are kept if the task stops early.

- B7 shl and shr, for every shift amount including 256 and above

- the parts of B9 that concern + - * << >> & | += -= (leave / and % for the division task)

Native helpers without division:
- D8 saturating_mul_u256_u64 and saturating_mul_u128_u64

If one of these turns out to contain a loop after all, say so and leave it for the division task: do not spend this task on loop invariants. Do not work in this task on B4, C1 to C3, D3 to D7, E1 to E5, F1 to F4 or G1 to G5.

As before: "returns" means the call returns normally and "panics" means it does not; a property about a returned value says nothing about inputs on which the function panics, and the panic conditions are separate properties (state them as "no execution panics" or "every execution panics", not as termination claims). Verify the deployed function bodies: no cfg(kani), default features, this crate's release profile (overflow-checks = true).

Report each property under its label, proved or refuted with a concrete counterexample. Do not weaken a statement silently, and list every library function whose documented behaviour a proof assumes instead of covering by proof.
